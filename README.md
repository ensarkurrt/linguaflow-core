# @linguaflow/core

LinguaFlow CLI ve yönetim araçlarının paylaştığı ICU message, çeviri formatı ve doğrulama
primitifleri. Uygulama runtime SDK'sı değildir; son kullanıcı uygulamalarında platform SDK'sını
kullanın.

```bash
pnpm add @linguaflow/core
```

Public repository, private LinguaFlow monorepo'sundan doğrulanmış kaynak snapshot'ı olarak üretilir.
